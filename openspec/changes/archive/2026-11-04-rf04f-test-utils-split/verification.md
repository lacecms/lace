## Implementation checks

- Repository contract: the 106-name pin passed; Node passed 213 cases and D1 passed 106, with listed names equal to the dynamic baseline. D1 ran outside the sandbox.
- Security contract: the new 17-name pin and both platform suites (17 each) passed; their listed names equal the dynamic baseline.
- Store: an AST-based comparison of method body source slices against the pre-split file found 51 original and 51 moved methods, with zero body differences. The largest store module is 469 lines. Source tests passed for test-utils (139), application (139) and server (139).
- The test-utils and config monoliths were split into typed companions; both exceptions left the test-typecheck baseline (141 → 139). Test-utils passed 139 cases and config passed 76. The existing config projection fixture was reused unchanged. Fixture typing supplies normalized block envelope defaults and empty media tags, types port fakes and narrows nullable lookups; the rename test now derives a complete model from `defineConfig` while retaining its requested hashes. The config list-field detachment test mutates its input with another valid field key rather than an invalid string; the detachment assertion is unchanged. A deliberately missing revision remains explicitly marked as malformed to preserve the singleton-guard test.
- Static listed titles matched the baseline for config (50), platform-node (71), and platform-cloudflare (79); test-utils matched 64 plus the new security pin (65). Dynamic lists matched config (76), platform-node (309), platform-cloudflare (218), and test-utils (138 plus the pin = 139).
- Final root gates passed with Node 24.22.1 and pnpm 12.3.4: `typecheck` (38 Turbo tasks), `lint` (22 Turbo tasks), `format:check`, `test` (64 Turbo tasks; 35 root files / 316 cases), and strict change validation. The docs link guard passed. The first full test attempt failed the unrelated Node SMTP implicit-TLS test when its fake server interpreted TLS handshake bytes as a command; the isolated test passed, and two subsequent full test runs passed.
