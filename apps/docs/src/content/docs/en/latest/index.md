Lace is a lightweight, self-hosted headless CMS for one website. Define structure in code, edit content in Admin, and render published snapshots into your Astro site.

This **latest** documentation follows **main** and targets **0.1.0-alpha.6**. It can describe changes before their artifacts are published. Check [GitHub releases](https://github.com/lacecms/lace/releases) for availability; a version label does not assert deployment verification.

Start with [Getting started](getting-started/), then choose [Docker/VPS or Cloudflare deployment](deployment/). Developers can learn [content modeling](content-modeling/) and [Astro integration](astro-integration/). Editors can follow [Editing content](editing-content/).
