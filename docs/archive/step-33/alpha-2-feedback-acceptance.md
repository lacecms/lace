# Alpha.2 field-trial feedback acceptance map

Session 33H evidence for [the alpha.2 field-trial log](lace-alpha-2-feedback.md) (§1–§6; row 7 is the log's unnumbered general diagnostics requirement). Sessions 33A–33G delivered the fixes; 33H proves them in packed consumers with the exact `0.1.0-alpha.3` candidate artifacts (`pnpm acceptance:release --artifacts`, see [step-33h-verification.md](step-33h-verification.md)). `stage:<name>` is an acceptance stage printed as `Acceptance: <name>` by the exact-artifact suite; a failing stage fails the run.

`tests/alpha-2-feedback-acceptance.test.mjs` fails when an item has no row, a referenced stage is not emitted by the exact-artifact journeys, a referenced file does not exist, a row is `open`, or a row for §3–§5 does not name the owner's real-account check. Status words: `resolved` (behavior delivered and proven), `decision` (resolved by a recorded decision and proven), `deferred` (outside this release), `open` (an unresolved defect; the suite is then not accepted).

Local stubs prove behavior, not a real Cloudflare account. Rows §3–§5 therefore name an **Owner check (34C)** that the owner performs on a real account after publication; until then those items are proven locally only.
